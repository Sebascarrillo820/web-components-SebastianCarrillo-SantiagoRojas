Descripción del proyecto

Este proyecto corresponde a una actividad evaluativa sobre el desarrollo de Web Components utilizando JavaScript y HTML Templates.

El objetivo es implementar un componente web reutilizable mediante una plantilla HTML (<template>), una clase de JavaScript y su utilización en diferentes instancias dentro de una página HTML.

Tecnologías utilizadas
HTML5: estructura de la página y definición de la plantilla mediante <template>.
JavaScript: creación, configuración y registro del componente web.
Web Components: tecnología utilizada para desarrollar elementos personalizados y reutilizables.
Git y GitHub: control de versiones y trabajo colaborativo.

¿Cómo ejecutar el proyecto?
Clonar el repositorio:
bash
git clone https://github.com/Sebascarrillo820/web-components-SebastianCarrillo-SantiagoRojas.git

Ingresar a la carpeta:
bash
cd web-components-SebastianCarrillo-SantiagoRojas

Abrir el archivo index.html en un navegador web.
Observar la representación del componente y sus tres instancias en la página.
Comprobar que las instancias del componente se visualizan correctamente.
